# Prueba Práctica — Unidad IV — ISR-401

## Ingeniería de Requisitos — Caso: Sistema de Gestión de Pedidos

Este repositorio contiene el desarrollo completo en LaTeX de las actividades P1 a P10 de la Prueba Práctica de la Unidad IV de la asignatura ISR-401, incluyendo los diagramas UML (clases, actividades y máquina de estados) elaborados en TikZ.

## 📁 Estructura del repositorio

```
├── main.tex                                # Documento principal en LaTeX
├── diagramas/
│   ├── class_diagram.tex                   # Diagrama de clases UML (P1)
│   ├── activity_diagram.tex                # Diagrama de actividades (P2)
│   └── state_diagram.tex                   # Máquina de estados (P3)
├── ISR401_PruebaPractica_UnidadIV.pdf      # PDF ya compilado
├── README.md
└── capturas_evaluacion.pdf                 # PDF ya compilado, de la evaluación en el SGA
```

## 🔧 Requisitos para compilar

- Distribución LaTeX (TeX Live, MiKTeX, etc.) con `pdflatex`.
- Paquetes utilizados: `inputenc`, `fontenc`, `times`, `mathptmx`, `xcolor`, `geometry`, `array`, `longtable`, `booktabs`, `tikz`, `adjustbox`, `hyperref`, `titlesec`, `enumitem`, `fancyhdr`. Todos vienen incluidos en cualquier instalación completa de TeX Live (`texlive-full` o `texlive-scheme-full`) o MiKTeX con instalación automática de paquetes.
